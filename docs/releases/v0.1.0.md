# OctoDeck v0.1.0 — Initial Release

This is the initial alpha release of **OctoDeck**, a local-first dashboard and browser companion designed for high-volume GitHub maintainers.

OctoDeck replaces passive notifications and slow web reloads with an action-oriented triage state machine, local SQLite caching, and an in-situ browser companion.

---

## Features

### Triage Engine & Workflow
* **Action-Oriented "Ack" Workflow:** Triage items into **Inbox**, **New Activity**, and **Acked** buckets.
* **Smart Transitions:** Automatically archives items upon your review/comment/merge, and restores them to the Inbox when new human activity occurs.
* **Bot Noise Filtering:** Detects and groups CI bots (`k8s-ci-robot`, `codecov`, `dependabot`) and slash commands (`/lgtm`, `/retest`, `/hold`), preventing noise from un-acking items.
* **Local Privacy:** Triage states, stars, and maintainer notes are stored strictly in a local SQLite database (`~/.octodeck/octodeck.db`) and are never sent to GitHub.

### Web Dashboard
* **Fast Navigation:** Instant search and sub-millisecond filtering across open/closed states, PRs/issues, organizations, repositories, authors, milestones, and labels.
* **Keyboard-Driven:** Complete keyboard shortcut support (`j`/`k` list navigation, `Enter` for details, `x`/`e` to Ack with auto-advance, `s` to Star, `o` to open on GitHub, `?` for cheatsheet).
* **Maintainer Organization:** Pin priority items to the top using stars, attach private markdown notes to any item, and customize repository/bot filters.
* **Themes:** Native support for System, Light, and Dark modes.

### Companion Chrome Extension
* **GitHub In-Situ Controls:** Injects an OctoDeck panel into the right sidebar of PRs and issues for one-click Ack, Star, and private notes.
* **Quick-Ack on Submission:** Adds an Ack option directly to GitHub's comment and review submission forms.
* **Timeline Noise Collapsing:** Replaces repetitive bot comments and slash commands on GitHub with expandable summary pills.
* **Discussion Markers:** Highlights where discussions were last viewed or acknowledged.
* **Desktop Notifications:** Displays toolbar badge counts and configurable OS-level notification alerts.

### Daemon & Sync
* **Embedded Daemon:** Single Go executable embeds the entire web app and serves it locally at `http://127.0.0.1:38274`.
* **Systemd Service:** Run `octodeck install` to configure a persistent user service.
* **Remote Support:** Supports remote development hosts and cloud workstations via SSH port forwarding.
* **Automated Maintenance:** Background garbage collection reconciles stale untracked items and prunes old closed issues while protecting starred/noted items.
